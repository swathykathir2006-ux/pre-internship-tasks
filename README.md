# JavaScript Coding Assignments

**Pre-Internship Training – Zentrion Technologies**

## Overview

This repository contains a collection of JavaScript programs developed during the pre-internship training period. These exercises focus on basic programming concepts, logical implementation, and problem-solving techniques.

## Assignment Details

### 1. Even or Odd Number
A program that identifies whether a given number is even or odd.

### 2. Largest of Three Numbers
A program to compare three numbers and determine the largest value.

### 3. Reverse a String
A program that reverses the characters of a given string.

### 4. Palindrome Checker
A program that checks whether a given string is a palindrome.

### 5. Sum of Array Elements
A program that calculates the sum of all values in an array.
